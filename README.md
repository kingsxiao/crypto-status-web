# CRYPTO STATUS · 加密货币市场状态

黑白极简风格（可切换主题色）的多页面加密货币市场观察应用：WebSocket 实时价格、牛熊周期判定、多指标合成的看多/看空信号、市场情绪分析、行情排序筛选与自选、实时换算器，以及带多指标工具的K线详情页。

## 技术栈

- **React 19 + TypeScript + Vite 7**
- **React Router 7**（HashRouter，静态托管免配置）
- **Tailwind CSS v4** + **shadcn/ui** 风格组件（Card / Badge / Table / Tabs / Progress / Tooltip 等）
- 自绘 SVG 图表（半圆仪表盘 / 火花线 / 蜡烛图 / 副图指标），无第三方图表库
- 纯前端，无后端依赖；所有指标在浏览器本地计算；全局数据 Context，页面切换不重新请求

### 功能要点

- **自选关注**：行情页星标收藏，本地浏览器持久化，跨页面同步
- **主题色**：石墨黑白 / 电光蓝 / 暗夜紫三套，头部一键切换，localStorage 持久化，首帧无闪烁
- **每页独立标题与描述**：切换页面同步更新 `document.title` 与 `meta description` / OG 标签（改善分享卡片与快照摘要）
- **PWA**：manifest + service worker（应用壳预缓存，可安装、弱网可开；行情 API 不缓存，币种图标 CacheFirst）
- **路由级详情页**：币种详情为独立路由，支持浏览器前进/后退、直达 URL

### 多空观点引擎（`lib/coinAnalysis.ts`）

任何币种可算的通用八指标引擎，仅依赖日线收盘/成交量序列，与总览页 BTC 信号共用评分口径：

| 指标 | 类别 | 权重 | 判定要点 |
| --- | --- | --- | --- |
| 价格 vs 200日均线 | 趋势 | 22% | 偏离幅度归一 |
| 均线交叉（50/200） | 趋势 | 14% | 金叉/死叉幅度 |
| RSI（14） | 动能 | 16% | 45–75 多头区；>75 超买逆势减分，<25 超卖逆势加分 |
| MACD（12/26/9） | 动能 | 16% | 柱值符号 + 收敛/发散 |
| 价格动量（7/30日） | 动能 | 12% | 混合涨跌幅归一 |
| 布林带位置（20,2） | 动能 | 10% | 上轨外超买减分、下轨外超卖加分（逆势） |
| 量价配合（5/20日） | 量能 | 10% | 放量上涨/下跌确认，缩量背离降级 |
| 距一年高点位置 | 周期位置 | 10% | 回撤深度（序列内自洽口径） |

- **币种详情页**：K 线下方渲染「多空观点」看板 — 综合分（±100）+ 结论 + 看多/中性/看空计数 + 逐指标读数、方向条、权重与一句话观点；独立拉取日线，不随图表周期切换，实时价参与计算
- **情绪页多空情绪总览**：技术面（BTC 六项）×50% + 情绪面（FNG 逆向 + 周变化顺势）×25% + 市场广度（涨跌家数比 + 平均涨幅）×25% → 综合情绪分，三张维度卡各自列出单项观点

## 数据来源与容错

| 用途 | 主源 | 备源 | 兜底 |
| --- | --- | --- | --- |
| 实时价格推送 | Binance WebSocket（miniTicker，秒级） | OKX WebSocket | Binance REST 20s 轮询 |
| K线（多周期） | Binance REST（500 根） | OKX REST（300 根） | CoinGecko 日线折线模式 |
| 行情快照 | CoinGecko | **Binance REST ticker/24hr**（限流时自动切换，字母头像占位） | 上一份快照缓存 |
| BTC 年线 | CoinGecko | **Binance REST klines**（365 日） | — |
| 全球市值 | CoinGecko | —（缺失时显示降级提示条） | — |
| 恐惧贪婪指数 | alternative.me | — | — |

- WebSocket 断线自动重连 3 次，失败自动降级到下一级数据源，头部实时显示当前数据链路状态（状态机由单测覆盖：假 WebSocket 驱动降级链与重试路径）
- 单一数据源限流/失败不影响整体可用；CoinGecko 快照按部分合并策略保留旧数据
- CoinGecko 请求统一走 `lib/cg.ts` 出口：同 URL in-flight 去重、429 自动退避重试、可选 `VITE_CG_KEY` 注入 demo key
- 跨资产判断数据（Defillama/fapi/CG top50）带 5 分钟 TTL 缓存，路由往返不重复拉取
- CoinGecko 限流（429/CORS 拒绝）时行情与BTC日线自动由 Binance 重建，图表/信号/换算全功能可用

## 指标合成方法

```
综合分 = Σ(指标分 × 权重) ÷ (总权重 × 2) × 100
```

| 指标 | 逻辑 | 权重 |
| --- | --- | --- |
| 价格 vs MA200 | 偏离幅度归一（趋势跟随） | 22% |
| 均线交叉 MA50/MA200 | 金叉/死叉幅度（趋势跟随） | 14% |
| RSI(14) | 45–75 为多头动能区，>75 超买逆势减分，<25 超卖逆势加分 | 16% |
| MACD(12,26,9) | 柱值符号 + 收敛/发散（动能） | 16% |
| 动量 7D/30D | 混合涨跌幅归一 | 12% |
| 恐惧贪婪指数 | 极端情绪逆向使用 | 10% |
| 距历史高点 | 周期位置强度 | 10% |

## 性能与压缩部署

- **预压缩产物**：`npm run build` 为每个资产同时生成 `.gz`（gzip）与 `.br`（Brotli，再省约 15%）。
  服务器按下发预压缩文件，省去运行时压缩的 CPU 开销：
  ```nginx
  # nginx：优先 Brotli，其次 gzip
  brotli_static on;   # 需要 ngx_brotli 模块
  gzip_static on;
  ```
- **首屏关键路径**（Brotli 实测传输）：主包 ~30KB + react-vendor ~64KB + CSS ~8.4KB ≈ **103KB**。
- **路由 chunk 预取**：导航 hover/获得焦点、币种行 hover 时预取目标页面 chunk；首屏渲染完成后空闲预取主路径页面 —— 点击导航/进币种详情零网络等待。
- **缓存策略**：`/assets/` 文件名带 hash，可配置 `immutable` 长缓存（`max-age=31536000`）；`index.html` 需 `no-cache` 以便发版后拿到新 hash 引用。
- **本地验证压缩部署**：`npm run preview:gzip` 起零依赖静态服务器（`scripts/gzip-serve.mjs`），按 `Accept-Encoding` 优先下发 Brotli，行为对齐 nginx 静态压缩。
